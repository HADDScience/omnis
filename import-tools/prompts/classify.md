# 카카오톡 대화 세션 분류

하드사이언스(바이오 스타트업) 단체방 대화다. 아래 입력은 `### id=... 방=... 날짜 (N건)` 헤더로 세션이 구분되어 있다.

## 라벨 (순서대로 적용, 먼저 걸리는 것으로 확정)

1. **업무** — 아래 중 **하나라도** 있으면 업무다.
   - 지시·요청 ("~해주세요", "~할까요?", "~좀 보내줘", "확인 부탁")
   - 진행 보고·결과 제출 ("~완료했습니다", "~보내드립니다", "수정했습니다")
   - 일정 조율 (미팅·행사·마감 시각 정하기)
   - 의사결정·피드백 ("이게 나은것 같습니다", "네 좋습니다", 시안에 대한 의견)
   - 자료·정보 요청 ("파일 있나요?", "주소가 어떻게 되죠?")
   → 사진이나 파일만 올렸어도 **그것이 작업 결과물 공유면 업무**다.

2. **정보공유** — 요청도 보고도 없이 기사·링크·자료만 공유. 반응이 없거나 단순 감탄만 있음.

3. **잡담** — 인사, 안부, 식사, 이동 알림, 이모티콘, 농담. 업무 내용이 전혀 없음.

4. **빈껍데기** — `Photo` `File:` `Voice Call` `N photos` 같은 행만 있고 **텍스트가 한 줄도 없음**.
   → 텍스트가 한 줄이라도 있으면 빈껍데기가 아니다. 이 라벨은 드물게만 나와야 한다.

**애매하면 업무로 분류한다.**

## 필드

- `id` — 헤더의 id 그대로
- `label` — 업무 / 정보공유 / 잡담 / 빈껍데기
- `topic` — 한 줄 요약 20자 내외. **원문을 그대로 복사하지 말고 요약**할 것.
- `project` — 관련 프로젝트·업무명 (없으면 null). 세션이 여러 프로젝트를 다루면 **가장 중심인 것 하나만**. 쉼표로 나열하지 말 것.
- `actionable` — 업무 카드(할 일)로 만들 가치가 있으면 true

## 프로젝트명 공통 어휘

해당하면 **아래 철자를 그대로** 재사용하라. 새 이름은 꼭 필요할 때만 만들고 짧고 일반적인 형태로 쓴다.
("홈페이지 관리"가 있으면 "웹사이트 관리"·"홈페이지 업데이트"를 새로 만들지 말 것.)

{{PROJECT_VOCAB}}

## 출력

JSON 배열 하나만. 다른 텍스트 없이. 마크다운 코드블록으로 감싸지 마라.
[{"id":"...","label":"업무","topic":"...","project":"...","actionable":true}, ...]

**입력의 세션을 하나도 빠뜨리지 말 것. 세션 수: {{COUNT}}**
