# 카카오톡 업무 대화 분석 스크립트

633세션 · 9,214메시지를 분류·집계한 도구다. 결과는 `docs/업무-유스케이스-카톡분석.md`.

| 파일 | 하는 일 |
|---|---|
| `load.py` | 카톡 CSV 로딩 · 빈 Date 행(연속 메시지)을 앞 메시지에 합친다 |
| `speech_acts.py` | 규칙 기반 화행 분류 (지시·수락·완료 신호) |
| `aggregate.py` | 세션·지시 단위 집계 |

원본 데이터(`sessions.json`, `final.json` 등)는 저장소에 넣지 않는다 —
실제 사내 대화라 공개 저장소에 올릴 내용이 아니다. `~/omnis-import/` 에 둔다.
