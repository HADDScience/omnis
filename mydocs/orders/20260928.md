# 2026-09-28 작업

사이트 세션이 "홈페이지 방문이 Neon 을 방문마다 깨운다" 며 묶어 달라고 요청했다.
재 보니 전제가 절반만 맞았다 — 주범은 방문이 아니라 Omnis 탭의 폴링이었다.

## 완료

| 상태 | 내용 |
|---|---|
| 완료 | **tailnet 등록 `ai-ecm` 걷기.** 작업지시자가 「쓸 필요 없다」고 확인했다. 배포는 이미 꺼져 있었고(`tailscale status` → stopped) 등록만 살아 있었다. 껐던 이유(Funnel 공유 토큰)는 vivoframe 주석과 계획서로 옮겼다. 계획 `mydocs/plans/2026-09-28-drop-ai-ecm-tailnet.md` |
| 완료 | **옛 주소 등록 `ai-ecm-com` 걷기.** VivoFrame 전환(9/22)의 마무리. 허브가 새 주소로 넘어가 붙잡고 있는 곳이 없어졌다. 등록 → 도메인 순서로 친다. 계획 `mydocs/plans/2026-09-28-drop-ai-ecm-com.md` · 검증 `mydocs/working/2026-09-28-drop-ai-ecm-com.md` |
| 완료 | **Neon 깨어 있는 시간 줄이기.** PR #67 머지·배포. ① 사람이 없는 탭은 폴링 정지 ② 밖으로 나가는 호출 전부 타임아웃 ③ 방문을 Redis 에 쌓아 하루 한 번 옮기기. 측정·실측은 `mydocs/working/2026-09-28-neon-wake-time.md` |

## 사람이 해야 할 것

| 상태 | 내용 |
|---|---|
| 대기 | **Upstash 약관 동의** — 브라우저에서만 된다. CLI 가 `integration_terms_acceptance_required` 로 막힌다. https://vercel.com/woochang4862s-projects/~/integrations/accept-terms/upstash · 동의하면 설치를 이어서 마무리한다. **동의 전까지 방문 묶기는 안 켜진다**(예전처럼 Postgres 로 바로 간다 — 배포는 안전하다) |
