# 채팅 검색 — 카톡식 검색 줄

상태: **승인 (2026-10-06).** 작업지시자가 카톡 PC 검색 화면을 주고 범위를 골랐다.
앞선 계획: [`archives/2026-10-06-chat-search.md`](archives/2026-10-06-chat-search.md) (PR #82).

## 바뀌는 것

| 지금 (PR #82) | 바꾼 뒤 |
|---|---|
| 검색창이 목록 · 입력창을 덮고 결과 **목록**을 보여 준다 | 패널 위에 **한 줄** 검색 줄. 대화와 입력창은 그대로 보인다 |
| 결과를 눌러야 그 자리로 간다 | 검색하면 가장 최근 결과로 바로 간다. ▲ 이전(더 옛) · ▼ 다음(더 최근). Enter = ▲, Shift+Enter = ▼ |
| 걸린 글자는 결과 목록에서만 굵게 | 대화 속 말풍선에서 걸린 글자에 노란 표시, 지금 결과는 더 진하게 |
| — | `3/120` 처럼 몇 번째인지 |
| — | 📅 날짜를 고르면 그날 첫 메시지 자리로 |
| — | 👤 보낸 사람을 고르면 그 사람 글만 ▲▼ (검색어와 함께 쓰면 둘 다 맞는 글) |
| 「검색 결과 자리를 보고 있습니다 · 최신으로」 줄 | 없앤다. ✕ 로 검색을 닫으면 최신 목록으로 돌아간다 |

## 단계

1. **API** — `/api/chat/search` 에 `authorId`(검색어 없이도 됨) · 첫 페이지에 `total`.
   `/api/chat/messages` 에 `at=<ISO>`(그 시각 이후 첫 글 주변, 없으면 마지막 글 주변). 주변 불러오기는 함수 하나로
2. **말풍선 표시** — CSS Custom Highlight API(`CSS.highlights`)로 `[data-message-body]` 안 글자에 범위를 건다.
   React 렌더(링크 · 칩 쪼개기)를 건드리지 않고 링크 · 멘션 안 글자까지 표시된다.
   지원하지 않는 브라우저(Firefox 140 미만)는 글자 표시 없이 지금 결과 말풍선 강조만 남는다
3. **검색 줄** — `components/chat/chat-search.tsx` 를 한 줄 막대로 다시 쓴다. 좁으면 아이콘 줄이 아래로 접힌다(`flex-wrap`).
   결과 id 목록은 20건씩 필요할 때 더 받는다. 이미 불러온 자리 안의 결과면 다시 받지 않고 스크롤만
4. **검증** — verify · build · API 실측 · Playwright(▲▼ · 날짜 · 사람 · 표시 · 320~200px · 터치 44px)
