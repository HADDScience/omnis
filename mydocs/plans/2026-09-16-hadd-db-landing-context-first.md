# HADD DB 랜딩 — 히어로를 회사 Context 에 넘긴다

## 왜

`/omnis` 랜딩은 화면에서 가장 큰 자리(히어로 문장 + 검색 막대 + 필터 칩)를 전부
`OmnisCard` 로 향하게 해 뒀는데, 운영 카드 수는 **0** 이다. 그 결과 지금 화면은:

| 자리 | 지금 보여주는 것 | 실제 |
|---|---|---|
| h1 "회사의 모든 지식, 한 번의 검색으로." | 검색 약속 | 카드 0건 |
| 부제 "0 카드 · 3 카테고리 · **매주 업데이트**" | 주간 갱신 | 갱신 주기가 없다. 0건과도 안 맞는다 |
| 필터 칩 5개 | `전체 / 즐겨찾기·0 / 기업정보·0 / 인력현황·0 / 지식재산권·0` | 전부 0. 눌러도 빈 화면 |
| 검색 막대 예시 | `검색 · "HPLC 세척 주기"` | 없는 카드 제목. 있는 것처럼 보인다 |
| 하단 3열 | "아직 카드 없음" × 3 | 화면 절반이 빈 상태 표시 |
| 가운데 타일 3개 | 매출 3.07억 · 연혁 170건 · 시장기업 41곳 | **유일하게 내용이 있는 곳** |

내용이 있는 것을 작게, 비어 있는 것을 크게 놓은 배치다.

## 무엇을 하지 않는가

검색 대상을 넓히는 일(`companyRecord`·`marketCompany`·NAS 색인)은 **이번 범위가 아니다.**
그건 `EmbeddingSource` 확장 + 마이그레이션 + 백필 + 검색 결과 화면이 필요한 별도 작업이다.
이번에는 화면 배치와 문구만 고친다 — 파일 하나.

## 단계

1. **Context 타일을 히어로로 올린다** — 검색 막대 위, 타일 자체를 키운다
   → 검증: 화면 최상단에서 매출·연혁·시장기업이 먼저 읽힌다
2. **부제를 사실로 바꾼다** — "매주 업데이트" 삭제. 카드가 0이면 카드 수를 내세우지 않는다
   → 검증: 0건 상태에서 부제에 거짓이 없다
3. **비어 있는 것을 숨긴다** — 카드 0건이면 필터 칩 행과 하단 3열을 렌더하지 않는다
   → 검증: 0건에서 "아직 카드 없음" 박스가 사라지고, 카드가 생기면 다시 나온다
4. **검색 예시를 실제 범위로 바꾼다** — 카드가 없을 때 없는 카드 제목을 예시로 쓰지 않는다
   → 검증: 0건에서 `"HPLC 세척 주기"` 가 보이지 않는다
5. **게이트** — `npm run verify` · dev 서버 실측 · 좁은 폭 감사

## 결정 기록

- **h1 을 바꾼다**: "회사의 모든 지식, 한 번의 검색으로." 는 검색이 카드만 훑는 지금
  참이 아니다. 검색 범위를 넓히는 후속 작업(A안)을 하면 그때 되돌릴 수 있는 문구다
- **카드 UI 를 지우지 않고 감춘다**: 카드는 AI 제안으로 쌓일 예정이다. `totalCards > 0`
  이면 예전 화면 그대로 돌아온다 — 조건부 렌더이지 삭제가 아니다
