# 웹 푸시 알림 — 탭이 닫혀 있어도 알림이 가게 한다

## 문제

알림은 `Notification` 행으로 쌓이지만, 사람에게 닿는 경로는 하나뿐이다 —
`components/layout/notification-bell.tsx` 의 15초 폴링과 sonner 토스트.
**탭이 열려 있고 보이는 동안에만** 뜬다. 업무 지시를 받아도 Omnis 를 안 열고 있으면 모른다.

## 무엇을 하는가

브라우저 웹 푸시(VAPID)를 붙인다. `public/` 에 manifest 도 service worker 도 없으므로
PWA 껍데기부터 만든다.

### 왜 웹 푸시인가

- `createNotification`(`lib/notifications.ts`)이 **알림 생성의 단일 진입점**이다. 화면·MCP·AI 재구성이
  모두 여기를 지나므로 푸시를 거는 자리가 한 군데다. 이미 그런 구조라서 고를 수 있는 선택지다
- 비용 0, 외부 심사 0, 외부 서비스에 묶이지 않는다. 카톡 알림톡(비즈채널·템플릿 심사·건당 과금)과
  네이버웍스 봇(앱 등록·Service Account JWT·사람↔웍스 userId 매핑)은 되돌리기 비싸다.
  전원 웍스 계정임이 확인되면 그때 웍스 봇을 **추가**한다 — 지금 고르지 않는다

### 왜 설치를 별도 버튼으로 유도하는가

iOS 는 **홈 화면에 추가한 PWA 안에서만** 푸시가 온다(16.4+). Safari 탭에서는 `Notification` API
자체가 없다. 그리고 iOS 에는 `beforeinstallprompt` 가 없어 **설치를 코드로 띄울 방법이 없다** —
사람이 공유 시트를 직접 열어야 한다. 그래서 "알림 켜기" 한 버튼으로는 iOS 사용자를 끝까지 데려갈 수 없고,
설치 → 권한 두 단계를 화면에 드러낸다.

- Android·데스크톱 Chrome/Edge: `beforeinstallprompt` 를 잡아 두었다가 버튼에서 `prompt()`
- iOS Safari: 공유 → "홈 화면에 추가" 를 그림으로 안내하는 시트
- 이미 standalone 으로 떠 있으면 설치 단계는 감춘다

### 폴링은 그대로 둔다

푸시를 거부했거나 설치하지 않은 사람에게는 지금의 토스트가 유일한 통로다. 푸시는 **더하는 것**이지
대체가 아니다. 요청 한도 문제(`tech/request-budget.md`)는 15초·비가시 탭 정지로 이미 정리돼 있다.

## 단계

| # | 무엇 | 검증 |
|---|---|---|
| 1 | `PushSubscription` 모델 + 마이그레이션 (로컬 DB) | `prisma migrate dev` 성공 · `\d "PushSubscription"` |
| 2 | `lib/push.ts` · `app/api/push/subscriptions/route.ts` · `createNotification` 훅 | 구독 저장 → 보내기 → 죽은 구독 삭제를 실제로 한 번 돌린다 |
| 3 | `app/manifest.ts` · `public/sw.js` · 아이콘 192/512/maskable | 배포본에서 `/manifest.webmanifest` · `/sw.js` 200 |
| 4 | 설정 카드 — 홈 화면 추가 유도 + 알림 켜기 | `pnpm run verify` · 좁은 뷰포트 감사 |
| 5 | 실기기 확인 (아이폰 1대 · 안드로이드 또는 데스크톱 1대) | 앱을 닫은 채로 알림이 오는가 |

## 경계

- **운영 DB 마이그레이션과 머지는 사람 승인 뒤에 한다.** 새 표를 읽는 코드가 먼저 나가면 화면이 깨진다
  (`AGENTS.md` Git 워크플로우). `pnpm run db:deploy` → 머지 순서
- VAPID 키는 `.env` 와 Vercel 환경변수에 넣는다. 공개 키만 번들에 실린다
- 구독은 **기기별**이다. 한 사람이 휴대폰·노트북을 따로 구독한다

## 남는 한계 (설계상 못 푸는 것)

- iOS 는 홈 화면에 추가하지 않으면 푸시가 오지 않는다. 1인당 한 번의 수동 조작이 필요하다
- iOS PWA 구독은 한동안 안 쓰면 만료된다. 만료되면 다음 접속 때 다시 구독해야 한다
- 이 둘은 코드로 우회할 수 없다. 화면에 사실대로 적는다
