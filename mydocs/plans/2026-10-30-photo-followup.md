# 사진 검색 후속 작업

사용자 지시: 묶음 화면 확인, 빌드 후 push·PR·머지 승인 요청, 기존 사진 잔여 처리,
운영 검색 10개 보고, 완료 워크트리 2개 정리, 카톡 이식 사진 설명 단계.
브랜치: fix/omnis-photo-answer. 기존 사진 검색 PR #121은 MERGED.

1. 기존 묶음 UI를 로컬 앱에서 PC·폰·200~320px로 확인한다. 사진 열기·이전/다음·닫기와 HTTP 응답을 기록한다.
2. 기존 backfill의 운영 dry-run으로 실제 잔여량을 확인하고, 승인된 Claude 구독 방식으로 미처리 사진만 이어 처리한다. 설명과 PHOTO 색인 누락을 각각 센다.
3. 카톡 첨부 뒤 사진 설명 단계를 추가한다. 이번 CSV의 메시지에 붙은 미설명 사진만 고른다(재실행 시 실패분 재시도). 기존 설명 생성·파싱·저장 함수를 공유하고 Claude 구독만 사용한다. dry-run에서는 모델 호출·DB 쓰기를 하지 않는다. --no-embed는 사진 색인도 생략한다.
4. 운영 검색 질의 10개의 실제 결과·근거 ID·순위와 사진 HTTP 상태를 사내 원문 결과에 남긴다. 공개 보고서에는 민감정보를 제외한 요약·명령·출력을 붙인다.
5. verify·build·범위별 시험을 실행하고 커밋 및 PR 본문을 준비한다. push·PR·머지는 사용자 승인 후 진행한다.
6. 병합이 확인된 깨끗한 워크트리 두 개를 정리한다. 브랜치·미병합 작업은 보존한다. 삭제할 두 경로가 불명확하면 사용자에게 확인한다.

승인 근거: 2026-10-30 사용자가 위 여섯 작업을 열거하고 “진행해줘”라고 지시했다.
