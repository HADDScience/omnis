# 세금계산서 지우기 — 그리고 「수정세금계산서는 지우지 않는다」 를 화면이 가르친다

## 왜

2026-10-29 구성원 문의: 「세금계산서를 재발급받았는데 기존 건을 지우고 다시 올릴 수 있나요? 수정 메뉴가 없어서요」.

- 세금계산서에는 **지우는 길이 없다.** API 는 견적 잇기 `PATCH` 하나뿐이다(`app/api/crm/invoices/[invoiceId]/route.ts`)
- 그런데 **수정세금계산서라면 지울 일이 아니다.** 당초(+) 는 두고 취소(−) · 재발행(+) 두 장을 올리면
  당초 승인번호로 한 묶음이 돼 금액이 한 번만 잡힌다(`lib/crm-receivables.ts` · 연도 합계는 부호째 더한다)
- 지우기가 필요한 건 **잘못 올렸을 때**와 **취소 뒤 일반 세금계산서로 새로 발행했을 때**다 — 이건 승인번호로 묶이지 않는다

즉 지우기를 만들면 사용자는 수정세금계산서에도 지우기를 누른다. 당초 장을 지우면 취소(−) + 재발행(+) = 0 이라
그 묶음이 「전부 취소」 로 보여 **받을 돈에서 사라진다.** 지우기 버튼이 곧 이 의도를 가르치는 자리여야 한다.

## 사용자가 스스로 알게 하는 방법 — 누르는 순간에 묻는다

설명 문서 · 도움말은 읽히지 않는다. 사용자가 「지우려는」 바로 그때가 유일하게 확실한 접점이다.

1. **지우기 창이 먼저 이유를 묻는다** (선택지 두 개)
   - 「수정세금계산서를 다시 받았어요」 → 지우지 않는다. 「이 장은 그대로 두고 취소(−) · 재발행(+) 두 장을 올리면
     자동으로 묶여 한 번만 셉니다」 + 「세금계산서 올리기」 링크. 지우기 버튼은 나타나지 않는다
   - 「잘못 올렸어요 · 취소하고 새로 발행했어요」 → 무엇이 함께 사라지는지(`DeleteRecordButton` 방식) 보여 주고 지운다
2. **묶인 장이 보이게 한다** — 수정 묶음에 든 장에 「당초 ○○ 와 한 묶음 · N장」 을 적는다.
   지금은 「수정」 배지뿐이라 묶였는지 화면에서 알 수 없다. 묶이는 게 보이면 지울 생각을 덜 한다
3. **업로드에서 반쪽 묶음을 잡는다** — 재발행(+) 만 올리고 취소(−) 가 없으면 「당초 + 재발행이 둘 다 매출로 잡힙니다 —
   취소(−) 장도 함께 올려 주세요」 를 묻는다. 지금은 반대 방향(당초를 나중에 올릴 때)만 막고 있다(`supersededBy`)

이번 타스크는 1 · 2 를 한다. 3 은 파서 · 묶음 판정을 건드리므로 별도 타스크로 둔다.

## 범위

| 단계 | 내용 | 파일 |
|---|---|---|
| 1 | `DELETE /api/crm/invoices/[id]` — 지우고 활동 기록. 이어진 견적의 `taxInvoicedAt` 은 그 견적에 남은 세금계산서가 없을 때만 비운다. 응답에 함께 사라진 입금 건수 | `app/api/crm/invoices/[invoiceId]/route.ts` |
| 2 | 지우기 창 — 이유를 먼저 묻는 두 갈래. 함께 사라지는 것: 입금 기록 N건 · 견적 연결. 수정 묶음에 든 장이면 「묶음이 깨져 받을 돈이 틀어진다」 를 맨 위에 | `components/crm/invoice-delete-button.tsx` (신규) |
| 3 | 목록 각 줄에 지우기 · 수정 묶음 표시 | `app/(main)/crm/invoices/page.tsx` |
| 4 | 문서 — `tech/crm.md` 에 지우기 규칙 한 단락 · 보고서 | `mydocs/` |

## 정한 것 (승인 필요)

- **NAS 원본 PDF 는 지우지 않는다.** 세금계산서 원본은 증빙이고 NAS 는 공용 저장소다. DB 기록만 지운다
- **입금 기록은 함께 지워진다**(스키마가 Cascade). 막지 않고 창에 건수 · 금액을 적는다
- **수정 묶음에 든 장도 지울 수는 있다** — 잘못 올린 경우가 있다. 다만 경고를 맨 위에 둔다
- 권한: 로그인한 구성원 누구나(견적 · 입금 지우기와 같다). 스키마 변경 없음

## 검증

- `pnpm run verify`
- 로컬 dev(운영 스냅샷)에서: 일반 장 지우기 → 목록 · 연도 합계 · 받을 돈 변화 / 「수정세금계산서를 받았어요」 를 고르면 지우기 버튼이 없다 /
  입금이 붙은 장 지우기 창에 건수가 나온다 / 견적에 이어진 장을 지우면 견적의 세금계산서 표시가 풀린다
- 거부되어야 하는 경우: 없는 id → 404, 비로그인 → 401
- `ux-rules` 11~30 자가 점검 · `narrow-audit`
