# 카톡 → 옴니스 시범 운영 측정

시범 운영을 이어 갈지 판단할 값을 주 단위로 본다. 작업지시자 지시(2026-11-06). UI 변경 측정([2026-11-04-ui-metrics.md](2026-11-04-ui-metrics.md))의 표 `UiEvent` 와 화면 `/settings/ui-metrics` 를 넓혔고 **스키마는 바꾸지 않았다.**

값은 숫자 · 식별자 · 시각뿐이다. 글 내용 · 방 이름 · 검색어 · 알림 제목은 측정 기록에 남지 않는다. 방 · 사람 이름은 관리자 화면이 그릴 때 그 표에서 읽는다.

## 측정 항목

| 항목 | 어디서 | 기록 |
|---|---|---|
| 푸시 발송 | `lib/push.ts` `deliverPush` | `push_sent` (서버). value = 그 사람의 기기 중 푸시 서비스가 받아 간 수 |
| 기기 수신 | `public/sw.js` push | `push_recv_s`. value = payload 의 `sentAt` 부터 받기까지 초. 그 방을 보고 있어 띄우지 않은 알림도 센다 |
| 눌러서 열기 | `public/sw.js` notificationclick | `push_open_s`. value = `sentAt` 부터 누르기까지 초 |
| 수신율 | 화면 집계 | 받음 수 / 보냄 수 (주마다) |
| 방별 하루 글 수 | `ChatMessage` 직접 집계 | 직접 = `sourceId` 없음 · 시스템 계정 아님 · NORMAL · 안 지움 · 옴니스 답 아님 · `__` 표식 아님 · 옴니스 1:1 방 아님. 카톡 = `sourceId LIKE 'kakao:%'` (시각은 카톡에서 쓴 시각) |
| 옴니스 질문 · 사진 답 | `OmnisQuery` 직접 집계 | 질문 수, 그중 출처에 PHOTO 가 있는 수 |
| 검색 | `api/chat/search` · `api/search` | `search_chat` · `search_global` (서버, 첫 쪽만). 같은 사람이 1분 안에 이어 보낸 것은 한 번 |
| 사진 찾기 | `api/chat/search` (전사방 + 검색어) | `search_photo` (서버). 위와 같이 묶는다 |
| 사람별 하루 활성 | 화면 집계 | 그날 화면 기록(받기 · 서버 발송 제외) · 직접 쓴 글 · 옴니스 질문 중 하나라도 있으면 활성 |

서버 전용 이름(`push_sent` · `search_*`)은 `uiEventBatchSchema` 의 목록에 없어서 화면이 보낼 수 없다. 이 기록들은 배포별 표 · 설문 대상 계산에서 뺀다(`lib/ui-metrics/server.ts` 의 `UI_ONLY`).

## 화면

`/settings/ui-metrics` 맨 위 「시범 운영」 칸, 관리자만. 같은 값은 `GET /api/ui-metrics/pilot?person=&room=`.

- 주(월요일 시작, 한국 시간) 8주 추이 표, 방별 직접/카톡 표(글 많은 30개 방), 사람별 쓴 날 표.
- 사람 필터는 모든 값에, 방 필터는 글 수에만 걸린다. 푸시 · 검색 · 질문은 방을 남기지 않기 때문이다.

## 재지 못하는 것

- **푸시 누락의 원인.** 푸시 서비스가 받아 간 뒤 기기에 닿지 않은 것은 「받음」이 없다는 것만 안다. 기기가 꺼졌는지, OS 가 버렸는지, service worker 가 보내기 전에 끊겼는지 구분하지 못한다. 기기가 받았지만 보고 요청이 실패한 것도 누락으로 보인다.
- **지연의 정확도.** 받기 · 열기 초는 기기 시계와 서버 시계의 차이다. 기기 시계가 앞서면 0 으로 둔다.
- **사람별 수신율의 정확한 짝.** 알림 하나하나를 잇는 식별자를 두지 않아 주 단위 합으로만 본다.
- **푸시가 꺼진 사람 · 구독이 없는 사람에게 갔어야 할 알림.** 보내지 않은 것은 「보냄」에 없다.
- **카톡으로 돌아간 정도는 이식한 만큼만** 보인다. 이식하지 않은 방 · 날짜의 카톡 글은 없다. 이식은 사람이 돌리므로 마지막 이식 뒤의 카톡 글은 다음 이식까지 0 으로 보인다.
- **카톡 이식 글의 사람 필터.** 옴니스 계정이 없는 사람의 이식 글은 시스템 계정 이름으로 들어가 사람 필터에 걸리지 않는다.
- **검색 횟수는 요청 기준**이다. 1분 묶기로 입력 중 자동 검색을 줄였지만 「검색 한 번」 과 정확히 같지 않다. 결과를 눌렀는지는 모른다.
- **화면만 열어 보고 아무것도 하지 않은 날.** 화면 기록은 동작(방 열기 · 메뉴 · 전송 등)에서만 생겨, 읽기만 한 날은 활성으로 안 잡힐 수 있다.
- **배포 전 기간.** 푸시 · 검색 기록은 이 변경이 운영에 나간 뒤부터 쌓인다. 글 수 · 질문 수는 표에 이미 있어 지난 주도 보인다.
