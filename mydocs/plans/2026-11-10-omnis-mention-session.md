# 단톡방 · 1:1 에서 @옴니스 로 부르기 + AI 세션 공유

작업지시자 결정(2026-11-10). 두 기능은 서로 전제라 한 PR 로 만든다. 배경 아이디어: [`ideas-from-ramp-glass-261110.md`](ideas-from-ramp-glass-261110.md) 3번.

## 1. 동작

1. 사람 방(단톡 · 1:1)에 `@옴니스 …` 를 쓰면 **언급 뒤 글이 그대로 프롬프트**다. 뒤가 비었으면 앞의 글을 쓰고, 둘 다 비면 부르지 않는다.
   `@옴니스님` · `@옴니스,` 는 부른 것이고 `@옴니스트` 는 아니다(`lib/omnis-mention-rules.ts`).
2. 글 API 가 글을 돌려준 **뒤에** 새 옴니스 세션(OMNIS_DM 방)을 연다 — 요청자 = 쓴 사람. 프롬프트를 첫 글로 넣고 실행한다.
3. 방에는 짧게만: 시작 「🤖 옴니스가 ○○님의 요청을 처리하고 있어요」, 끝 「🤖 옴니스 답 · (답 앞 두 줄 요약)」. 확인 대기 · 실패 · 한도 · 멈춤도 한 줄씩.
   안내 줄은 가운데 알약이고 「열기」 를 누르면 그 세션으로 간다(`ChatMessage.sessionRoomId`).
4. 카톡 이식 글(`sourceId kakao:%`)의 @옴니스 는 실행하지 않는다 — 이식은 글 API 를 지나지 않고, 규칙도 한 번 더 거른다.
5. 에이전트가 꺼져 있거나(키 · 승인 서명 없음) 요청자가 한도에 닿았으면 세션을 만들지 않고 「옴니스를 부르지 못했어요 · 까닭」 한 줄만 남긴다.

## 2. 공유 — 권한은 새로 만들지 않는다

- 세션 방은 `ChatRoom.originRoomId` 로 연 방을 가리키고, **참여자 행을 그 방과 같게 둔다.** 초대 · 나가기 때 `syncSessionMembers` 가 함께 맞춘다.
- 그래서 roomAccess · 방 목록 · 검색 · 첨부(lib/file-access.ts) · MCP(list_rooms · list_chat · search_knowledge)가 쓰는 「지금 참여자」 조건이 고칠 것 없이 공유 세션에도 맞는다. 방 밖 사람에게는 어느 길로도 404 다.
  - 버린 안: 세션 권한을 매번 `roomAccess(originRoomId)` 로 풀기 — 참여자 조건을 쓰는 곳(목록 · 검색 · 피드 · 첨부 · MCP)을 하나도 빠짐없이 고쳐야 해서, 하나만 놓쳐도 샌다.
- 참여자는 세션에 이어서 묻는다. 남의 글은 왼쪽에 이름과 함께 보인다. 목록에는 「공유됨 · 방 이름」.
- 개인 세션(방 밖에서 연 것)은 지금처럼 본인만. 방 밖 세션의 수동 공유 · 인계는 이번 범위 밖 — 공유 대상을 `originRoomId` 대신 표로 두면 넓힐 수 있다.

## 3. 실행 · 확인 카드 · 비용

- 실행(AgentRun)은 그 글을 쓴 사람의 것이다. 확인 카드는 **그 실행의 요청자만** 누른다 — 서버는 원래부터 `checkDecision` 이 실행 주인만 받는다. 화면은 다른 참여자에게 버튼 대신 「요청한 ○○님만 확인할 수 있어요」.
- 비용(AiUsage)과 사람별 상한(#183)은 실행 주인에게 잡힌다. 이어 묻기는 그 글을 쓴 사람 몫이다.
- 한 방에 실행은 하나 — 공유 세션은 여러 사람이 묻기 때문에 방마다도 잠그고(사람 → 방 순서), 남의 실행이 돌고 있으면 409. 남의 실행이 도는 동안 다른 참여자 화면은 「옴니스가 ○○님의 글에 답하는 중이에요」 를 띄우고 몇 초마다 다시 읽는다(남의 스트림에는 붙지 않는다).
- 새 글이 오면 확인을 기다리던 앞 제안은 버린다(원래 규칙). 공유 세션에서는 다른 참여자의 새 글도 요청자의 대기 카드를 버린다 — 낡은 제안을 남겨 두지 않는다는 원래 규칙을 그대로 둔다.
- 방 안내는 @옴니스 로 연 첫 실행(`AgentRun.notifyOrigin`)만 — 이어 묻기는 방에 알리지 않는다. 끝 안내는 조건부 갱신으로 한 번만.

## 4. 스키마

| 칸 | 뜻 |
|---|---|
| `ChatRoom.originRoomId` | 세션을 연 사람 방. 관계(SetNull) + 색인 |
| `ChatMessage.sessionRoomId` | 안내 줄이 가리키는 세션. 관계 없음(ChatMessage ↔ ChatRoom 관계가 둘이 되면 기존 관계 이름까지 바꿔야 한다) |
| `AgentRun.notifyOrigin` | 방에 끝을 알릴 실행 |

마이그레이션 `20261110180000_omnis_mention_session` — 칸만 더한다. 백필 없음(기존 세션은 개인 세션).
