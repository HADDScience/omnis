# 랜딩페이지 모션 스토리

사용자 승인 후 구현, 로컬 확인 피드백 반영 중. 기존 비로그인 루트 랜딩을 변경한다. 로그인 사용자의 /chat 이동은 유지한다.

## 목표와 연출

스크롤이 페이지를 밀기보다 영상의 재생 위치를 움직이는 듯한 흐름을 만든다. 기존 브랜드 아이콘과 제품 화면의 시각 언어를 사용한다.

1. **스크롤 도입**: 중앙 앱 아이콘만 표시 → 아이콘이 헤더 자리로 이동하면서 헤더 등장 → “HADD Science는 Omnis와 함께 일합니다”가 떠오름 → Omnis 단어를 장면 사이에서 연결해 “Omnis는 회사의 맥락을 이해하며 일합니다”로 전환. 장면 사이에는 페이드와 위치·크기 변화를 결합한다.
2. **문제와 AX**: Claude·GPT·Gemini·Grok 등 모델 이름과 맥락 없는 가상 응답을 모션그래픽으로 표현한다. 실제 모델 성능의 비교나 실제 응답으로 보이지 않게 가상 상황임을 밝힌다. “업무에 AI 도입하고 싶은데…”, “무슨 AI가 좋지?”, “업무를 시켜도 제대로 된 결과가 안 나와…”를 분산 배치한다. 중앙 문구는 “AI 전환 → AI Transformation → AX → AX 어떻게 하지? → Omnis와 함께라면 가능합니다” 순서로 전환한다.
3. **자동 업무 시연**: PC 화면이 보이는 시점에 스크롤과 독립된 타임라인을 시작한다. 실제 PC 메신저의 내비게이션·새 채팅·대화·업무 카드 형태를 재현한다. 가상 업무는 A 사원의 고객사 제안서 초안 작성으로 통일한다. 관리자의 생각 → 새 채팅 → 업무 지시 → AI의 고객사·기한·범위 재질문 → 추가 정보 → 업무 생성 → A 사원 화면 전환 → 오늘 할 일 질문 → 회사 맥락에 따른 우선순위와 근거 → 최우선 업무 시작 요청 → 사내 정보·웹 검색·MCP 도구 활용 과정 → 출처를 구분한 제안서 초안 표시로 끝낸다. 실제 데이터·도구 호출은 하지 않는다.
4. **후반 구성**: 시연 종료 후 스크롤로 도입 효과 세 가지(명확한 지시, 맥락에 따른 우선순위, 실행과 초안까지 연결), 비전 “회사의 맥락을 파악하고 움직이는 AI”, 들어가기·문의하기 CTA, 푸터를 표시한다. 수치 성과는 만들지 않는다. 들어가기는 /login, 문의 경로는 기존 저장소에서 확인된 연락 수단을 사용하며 없으면 페이지 내 문의 안내를 제공한다.
5. **접근성과 검증**: 모바일에서 줄바꿈·화면 축약을 적용한다. 자동 시연에 일시정지·다시 보기·건너뛰기를 제공하고 스크롤을 강제로 가두지 않는다. reduced-motion에서는 이동을 줄이고 내용을 읽을 수 있게 한다. pnpm run verify, pnpm run build, 가능한 로컬 브라우저 시연·역스크롤·좁은 화면·모션 감소 검증과 narrow-audit 및 사용자 흐름 e2e를 수행하고 실행 출력과 미실행 사유를 working 보고서에 남긴다.

## 구현 경계

- 랜딩 컴포넌트, 전용 스타일, 업무 시연 컴포넌트와 필요한 범위의 검증만 변경한다. 새 애니메이션 의존성은 우선 추가하지 않는다.
- 도입은 sticky 영역과 스크롤 진행도를, 업무 시연은 가시성에 연동한 자동 타임라인을 사용한다. 화면 밖에서는 재생을 멈춘다.
- 업무 시연은 제품 UI를 재현한 가상 시연이다. 실제 서비스에서 작업을 만들지 않는다.
- 단계별 로컬 커밋. push·PR·배포는 별도 사용자 승인 후 수행한다.

## 승인 후 단계

1. 스크롤 장면과 아이콘·문구 연결 구현 → 순방향·역방향 전환 확인.
2. 제품 UI 기반 자동 업무 시연 구현 → 전체 시나리오와 재생 제어 확인.
3. 효과·비전·CTA·모바일 대응 → 링크와 좁은 화면 확인.
4. 품질 게이트 실행 및 실측 보고서 작성 → 사용자 검토.

## 로컬 검토 후 수정 지시

다른 AI에 질문하고 답을 받는 장면 → 흩어진 고민 문구 → AI 도입 → AI 전환 → AX 어떻게 하지? 순으로 수정한다. 업무 시연은 실제 AgentCard 확인/실행 상태 컴포넌트를 재사용하고, 실제 채팅 목록·새 대화 메뉴·입력 UI를 참고한다. 클릭 포인터를 표시하며 대화를 누적하고 내부 스크롤로 이어간다. 업무 생성 완료를 확인 후 명확히 표시한다. 사용자 수정 지시로 승인된 기존 범위의 보완이다.

추가 로컬 피드백: 컨트롤러를 시연 화면 안 호버/키보드 오버레이로 이동하고 터치에서는 상시 노출한다. 시연 면적을 확대한다. 실제 Button·Hugeicons를 사용하고 헤더 도착 후 아이콘을 고정 표시한다. 질문창은 기존 glass를 활용한다. 외부 AI 화면은 각 서비스의 채팅 외관을 재현한다. 도입 장면은 휠/스와이프 한 동작마다 한 장면씩 이동하며 키보드도 지원한다. 시연 이후 일반 스크롤은 유지한다.

후속 지시: 중앙 아이콘 부유 효과 복원, 은은한 등장, 영문 eyebrow 및 하단 진행 막대 제거, 공유 Omnis 텍스트 히어로 전환. 업무 시연은 소개 상태에서 추가 스크롤로 헤더 아래 화면을 채우고 그 시점부터 자동 재생한다. 대화 안의 스크롤이 페이지 이동을 막지 않게 한다.

추가 지시: 시작 안내는 선 없이 블링크. 공유 Omnis는 두 자리 사이 직선 이동 후 문구 타이핑. AI 질문창 가로 확장→타이핑→Claude부터 순차 등장과 카드 hover 확대. 고민 문구를 10개로 늘리되 이모지는 3곳만 사용한다. 고민을 유지한 채 중앙 AI 도입을 표시하고 다음 스크롤에서 중앙으로 흡수하며 AI 전환으로 바꾼다. 헤더는 구분선과 기존 하드사이언스 로고, 폰트는 디자인 시스템 Pretendard를 사용한다. 시연 컨트롤은 포인터 활동 후 2초 뒤 숨기며 키보드 focus-visible은 유지한다. 시연 스크롤은 한 제스처에 최대 150px로 제한한다.
