# AI 비용 — 작게 시작해 쓰는 만큼 늘린다

작업지시자 요청(2026-11-10). 11/2 정기회의 예산안(월 11만원 잠정)을 실측 없이 굳히지 않고, 사람별로 작게 열어 두고 관리자가 바로 올린다.

## 상한

- **사람별 하루 상한** + **회사 월 상한**(원). 회사 전체가 나눠 쓰는 하루 상한은 두지 않는다.
- 기본값: 1인 하루 1,000원 · 월 110,000원. env `OMNIS_AI_USER_DAILY_KRW` · `OMNIS_AI_MONTHLY_KRW` 로 바꾸고,
  관리자 화면(`/settings/ai-budget`) 값이 있으면 그것을 쓴다(AppSetting `ai_budget`, 재배포 없음). 사람별 예외 상한도 거기서.
- Global Config 가 아니라 DB — 점검 스위치는 매 요청 읽는 값이라 Global Config 였고, 이 값은 옴니스 실행 시작 때만 읽어 DB 한 번이면 된다(Hobby 읽기 한도도 아낀다).
- 닿으면: 새 옴니스 실행만 받지 않는다(429). 이미 돌던 실행 · 확인 카드는 그대로 끝난다(실행당 200원 상한은 그대로).
  안내는 입력창 위에 남고, 관리자에게는 「한도 올리기」 → 새 값 확인 → 「올리기」(한 번 더 확인). 올리기만 된다 — 내리기는 관리 화면.
- 월 상한이 먼저 — 그쪽이 닿았으면 사람별 상한을 올려도 소용없다.
- 데모 하루 상한(`OMNIS_AGENT_DAILY_KRW` · `OMNIS_AGENT_USER_DAILY_RUNS`)은 그대로 둔다.

## 원천 · 알림

- 원천은 `AiUsage.costKrw` 하나. 에이전트 · 사진 설명은 원래 남았고, Gemini 호출(업무 카드 정리 · 재구성 · 검색 임베딩 · 옴니스 질문 · 지식 카드 · 연혁 제안 · 번역 · 세금계산서 판독 · 칼럼)은
  토큰만(GeminiUsage) 남던 것을 모델과 함께 원으로도 남긴다(`lib/gemini-usage.ts` → `geminiAiUsageRow`). GeminiUsage 는 호출 한도용으로 그대로 쓴다.
- 요금표에 없던 `gemini-3.6-flash`(운영 기본) · `gemini-embedding-001` 은 추정 단가(넉넉히)로 넣었다 — 확인하면 `lib/ai-pricing.ts` 를 고친다.
- 월 누적이 80% · 100% 에 닿으면 알림 받는 사람에게 옴니스 알림 + 운영 메일(`lib/ai-budget-alerts.ts`). 같은 달 같은 단계는 AppSetting 표시로 한 번.
- 알림 받는 사람(기능 요청 · 비용 알림 공용, `lib/notify-recipients.ts`): 관리자 화면에서 고른 사람. 비어 있으면 예전처럼 ALERT_EMAIL_TO 와 이메일이 같은 재직 계정.

## 화면

- 마이 → 사용량: 오늘 내 사용 · 이번 달 회사 전체(상한 대비 %), 사람별(관리자는 전체 · 구성원은 자기) · 날짜별 건수 · 비용.
- 관리자: 마이 → 앱 정보 → 「AI 비용 상한」 = `/settings/ai-budget`.
