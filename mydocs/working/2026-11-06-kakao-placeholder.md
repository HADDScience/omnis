# 카톡 첨부 자리표시를 본문에서 뺀다

지시: 카톡에서 옮긴 글에 `Photo` · `3 photos` · `File: 이름` 같은 내보내기 자리표시가 본문으로 보인다.
사진·파일이 실제로 붙은 글에서는 자리표시를 뺀다.

## 자리표시 꼴 (2026-11-06, 원본 마스터 18,019건 실측)

| CSV(PC) | 휴대폰 txt | 받을 실물 | 이번 처리 |
|---|---|---|---|
| `Photo` | `사진` | 사진 | 붙었으면 뺀다 |
| `N photos` | `사진 N장` | 사진 N장 | 붙었으면 뺀다 |
| `Video` | `동영상` | 영상 | 붙었으면 뺀다 |
| `File: 이름` | `파일: 이름` | 파일 | 붙었으면 뺀다 |
| `Emoticon` | `이모티콘` | 없음 | 그대로 |
| `Voice Call` · `KakaoTalk Profile` | — | 없음 | 그대로 |

- 휴대폰 txt 의 한국어 자리표시는 읽을 때 CSV 말로 바뀐다(`mobileToCsvWords`). DB 에는 영어 꼴만 있다.
- 자리표시는 늘 글 하나를 통째로 차지한다. 사람이 쓴 글과 한 글에 섞인 경우는 없고, 삭제 표시 줄
  (`The message has been deleted.`)이 뒤에 붙은 경우만 있다. 그 줄은 남긴다.
- 음성 메시지 · 연락처 · 지도 · 송금 같은 꼴은 마스터에 없다.

## 규칙

- 이식 5단계(`steps/media.ts`)가 이번에 하나라도 붙인 글만 본문을 고친다. 자리표시 줄만 빼고 다른 줄은 남긴다.
- 못 붙인 글(원본 없음 · 삭제 · 제외 대화 옆)은 그대로 둔다. 자리표시라도 남아야 무엇이 있었는지 보인다.
- `N photos` 인데 N장보다 적게 붙은 글도 뺀다.
- 메시지 `sourceId` 는 CSV 원문으로 셈하므로 DB 본문을 고쳐도 다시 넣지 않는다.
- 이미 들어간 글은 `import-tools/strip-placeholders.ts` 로 고친다. 기본은 보기만 하고, `--apply` 는 원래 본문을 노트북에 먼저 백업하며,
  `--restore` 로 되돌린다. 고칠 때와 되돌릴 때 모두 본문이 예상과 같은 글만 바꾼다.

## 화면

- 글 없이 첨부만 있는 글은 앱에서 사진만 보낸 글과 같은 꼴이다. 폰 메신저에서는 빈 말풍선을 숨기고(`empty:hidden`),
  PC 에서는 높이 0 이다. `tests/feature/chat-room-media.spec.ts` 가 사진 · 여러 장 · 파일 세 꼴을 본다.
- 방 목록 미리보기는 본문이 비면 「사진」 · 「사진 N장」 · 「동영상」 · 「파일」 로 보인다(`attachmentPreview`).
  업무방 미리보기(`taskHeads`)는 SQL 이라 이번에 바꾸지 않았다.

## 하지 않은 것

- 운영 DB 쓰기. 건수 · 예시는 운영을 읽기만 해서 셌다(노트북 보고서).
- 고친 글의 검색 색인 다시 만들기. 색인에는 `Photo` 같은 짧은 말이 남는다.
- 카드에 저장된 원문 기록(`Task.sourceMessages`)의 자리표시.
