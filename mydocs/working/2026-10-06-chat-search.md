## API 실측

`GET /api/chat/search?roomId=default-room&q=…` (서버 `elapsedMs`, 색인 없음):

| 검색어 | 결과 | 더 있음 | 서버 |
|---|---|---|---|
| 견적 | 20 | 예 | 24ms |
| 세금계산서 | 20 | 예 | 14ms |
| ADD | 20 | 예 | 4ms |
| 회의 | 20 | 예 | 14ms |
| a (한 글자) | 0 | — | 조회 안 함 |
| 없을것같은검색어zz | 0 | 아니오 | 12ms |

1만 4천 행에서 24ms 이하라 `pg_trgm` 색인은 두지 않는다(계획서 기준 300ms).

| 확인 | 결과 |
|---|---|
| 「견적」 전 페이지 넘기기 vs DB 직접 집계 | 6페이지 · 120건 · 중복 0 · 누락 0 (DB 120건) |
| 지운 글 | 결과에 안 나옴 |
| 시스템 글 · 업무 카드 (DB 60건) | 「TASK_CREATED」 검색 0건 |
| `around` (2025-09-06 글) | 31건, 대상 15번째, 오름차순, 앞·뒤 더 있음 |
| `around` (가장 최근 글) | 16건, 뒤 더 없음 → 점프 보기로 들어가지 않는다 |
| `after` + `take=30` | 30건 |
| `around` 없는 id | 404 |

## 화면 (Playwright, 1280×860)

검색 → 「더 보기」 2번(60건) → 가장 오래된 결과(2026-05-14 김아리, 견적서 첨부) 클릭:

- 「검색 결과 자리를 보고 있습니다 · 최신으로」 줄이 뜨고 대상 1줄만 강조, 목록 보이는 범위 안
- 맨 아래로 스크롤 → 31 → 61줄 (뒤 30건 이어 붙음)
- 「최신으로」 → 점프 줄 사라지고 최신 목록
- Esc 로 검색창 닫힘
- 콘솔 오류 0
