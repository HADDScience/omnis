## 입구 — 시나리오마다 하나

「새로 만들기」 메뉴 한 곳: 샘플 요청 → 견적 → 세금계산서 등록 → 입금 확인 (일이 흘러가는 순서).
CRM 세금계산서 화면의 업로드 칸은 지웠다 — 입구가 둘이면 어느 쪽인지 고민하게 된다.

## 견적 ↔ 세금계산서

- 견적을 「완료」 로 바꿔도 `taxInvoicedAt` 이 채워지지 않음 · 허찬에게 `crm_invoice_request` 알림 → 누르면 그 견적이 걸린 등록 화면
- HADD250305-005(가천대 의과대학, 1,980,000): 산학협력단 앞 같은 금액 계산서를 제안 → 「이 세금계산서가 맞아요」 → 연결 저장 확인

## 입금 · 미수

- 부분 입금 → 남은 금액 표시 · 남은 금액 초과 → 409 · 전액 → 미수에서 빠짐
- 입금 기록이 0건이면 30일 넘은 23건 · 4.69억이 전부 미수로 보였다 → 첫 화면에 「이미 받은 것 걷어내기」 한 번(60일 넘은 것 기본 체크, 입금일 = 발행일, 메모로 구분)
