# 나와의 대화 · 같은 상대의 1:1 은 하나

## 한 것

- **나와의 대화**: 기존 1:1(`kind=DM`)을 쓴다. `dmKey` 를 `나:나` 로 두어 사람마다 하나이고 참여자는 나뿐이다. DB 스키마 변경 없음. 입구는 「사람과 대화」 맨 위 줄이고, 처음 연 뒤부터 방 목록에 보인다
- 방 · 글 · 검색 · 첨부의 접근은 다른 1:1 과 같은 코드다(참여자 조건). 관리자 예외도 없다
- **같은 상대의 1:1**: 이미 `dmKey` 유일 제약으로 하나뿐이고, 이식 도구도 같은 열쇠를 쓴다. 코드 변경 없이 시험으로 못 박았다. 단톡방은 고른 사람이 같아도 새로 만든다

## 운영 실측 (2026-11-03, 읽기 전용, 합치지 않음)

- DM 방 5개 · 중복 0쌍. `dmKey` 없음 0, 참여자 2명이 아닌 DM 0, `dmKey` 와 참여자 불일치 0
- 참여자 2명인 단톡방(GROUP) 1개 `kakao-aibio-room`(글 79건)의 두 사람이 이식 1:1 `kakao-dm-fb2043c5…`(글 184건)과 같다. 이름 있는 단체 대화로 이식된 방이라 1:1 규칙 대상이 아니다
