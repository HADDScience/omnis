## 3. 실측 출력

### 타입 가드가 실제로 막는가

`IP_CASE` case 를 지우고:

```
components/omnis/omnis-ask.tsx(90,16): error TS1360:
  Type '"IP_CASE"' does not satisfy the expected type 'never'.
```

되돌리니 통과. 화면을 안 고치고 enum 만 늘리면 빌드가 먼저 깨진다.

### 오류 신고 엔드포인트

`next start -p 3123` 에 대고:

```
POST /api/errors (정상)   → {"ok":true,"mailed":false,"configured":false}
POST /api/errors (같은 것) → {"ok":true,"mailed":false,"reason":"중복"}
POST /api/errors (message="") → status=400
```

서버 로그에는 두 건 모두 남았다 — 중복 억제는 **메일만** 막고 로그는 다 남긴다.

```
[client-error] 언제:   2026-09-04T02:16:18.228Z
누가:   비로그인
어디:   http://localhost:3123/omnis/ask
범위:   페이지
```

### 빌드

`npm run build` exit 0. `npm run typecheck` 통과.

`npm run lint` 은 **기존부터** 오류 1건 · 경고 43건이다 (이번 변경과 무관).

```
components/settings/linked-accounts.tsx 45:5
  rule=react-hooks/immutability
  `reload` accessed before it is declared
```

함수 선언이라 호이스팅으로 런타임은 멀쩡하다. React Compiler lint 가 잡는다.
고치려면 `reload` 를 `useEffect` 위로 올리면 된다 — 이번 작업 범위 밖이라
손대지 않았다.
