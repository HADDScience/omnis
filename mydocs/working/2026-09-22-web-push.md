## 실측

### 발송 규칙 — `scripts/verify-push.ts`

가짜 푸시 서비스(자체 서명 https)를 세워 상태 코드별 처리를 실제로 돌렸다.
web-push 는 평문 http 로는 보내지 않는다(TLS 오류로 끊긴다) — 그래서 https 다.

```
$ set -a; source .env; set +a; pnpm exec tsx scripts/verify-push.ts
  ✓ 설정이 갖춰졌다고 본다
  ✓ 구독이 없으면 0건
  ✓ 살아 있는 구독으로 1건 나간다
  ✓ 푸시 서비스가 실제로 요청을 받았다
  ✓ 살아 있는 구독은 남는다
  ✓ 410 은 발송 0건
  ✓ 410 이면 구독을 지운다
  ✓ 지운 뒤 행이 남지 않는다
  ✓ 500 은 발송 0건
  ✓ 500 에는 구독을 지우지 않는다        ← 거부되어야 하는 경우
  ✓ 일시 오류 뒤에도 구독이 남는다
  ✓ 사용자를 지우면 구독도 사라진다

12건 통과 · 0건 실패
```

## 돌리지 못한 것

- **실기기 확인 — 아직 남아 있다.** 아이폰에서 홈 화면에 추가 → 알림 켜기 → 앱을 닫은 채로
  도착하는지는 사람이 기기를 들고 해야 한다. 운영에서
  `사파리로 omnis.haddscience.com → 공유 → 홈 화면에 추가 → 그 아이콘으로 열기 →
  설정 → 기기 알림 → 알림 켜기 → 시험 알림` 순서다. **크롬으로 추가하면 안 된다** —
  iOS 는 사파리에서 추가한 PWA 에만 푸시를 준다
- **로그인이 필요한 화면.** 로컬 DB 는 운영 스냅샷이고 `passwordHash` 를 가리지 않아
  (`scripts/mask-snapshot.sql`) 비밀번호를 모른다. `/settings` 카드의 상태별 표시와
  `scripts/narrow-audit.mjs`(좁은 뷰포트 감사)는 `AUDIT_USER`·`AUDIT_PASS` 가 있어야 돈다
- **ux 규칙 17 (Card 3+ 수직 스택).** `/settings` 이 카드 3장이 됐다. 규칙의 적용 범위는
  detail/dashboard 페이지라 위반은 아니지만, 설정이 더 늘면 Tabs 로 갈라야 한다

## 배포 — 끝났다 (2026-09-22)

순서는 「키 → 마이그레이션 → 머지」였다. 새 표를 읽는 코드가 먼저 나가면 설정 화면이 500 이고,
키가 없으면 카드가 "서버에 푸시 키가 설정되지 않았습니다" 를 띄운다.

1. **Vercel 환경변수** — `omnis-hadd` 의 Production · Preview 양쪽에 3개
   (`NEXT_PUBLIC_VAPID_PUBLIC_KEY` Config · `VAPID_PRIVATE_KEY` Secret · `VAPID_SUBJECT` Secret).
   로컬 `omnis-local/.env` 와 **같은 쌍**이다 — 키를 갈면 기존 구독이 전부 무효가 된다
2. **운영 DB** — `prisma migrate deploy` 로 `20260922020000_push_subscription` 적용.
   direct 연결(`POSTGRES_URL_NON_POOLING`)로 나갔다. 적용 뒤 운영에서 직접 읽어 확인:

   ```
   컬럼 : id · userId · endpoint · p256dh · auth · userAgent? · createdAt
   인덱스: PushSubscription_endpoint_key · PushSubscription_pkey · PushSubscription_userId_idx
   외래키: PushSubscription_userId_fkey
   행 수 : 0
   ```

3. **머지** — PR #59, main `6234c83`. 데모(`omnis-demo`)는 빌드가 `prisma migrate deploy` 를
   돌리므로 표가 자동으로 생겼다

운영 배포가 Ready 된 뒤 `omnis.haddscience.com` 에 직접 쳤다:

```
/manifest.webmanifest      200 application/manifest+json
                           {"name":"Omnis — HADD Science","short_name":"Omnis",
                            "start_url":"/","scope":"/","display":"standalone", …}
/sw.js                     200 application/javascript
/icon-192.png              200 6073B
/icon-512.png              200 17983B
/icon-maskable-512.png     200 17584B
/api/push/subscriptions     401   (미인증 차단)
```

### 이 과정에서 알게 된 것

- **프리뷰가 운영 DB 를 쓴다.** `DATABASE_URL` 이 Production 과 Preview 양쪽에 걸려 있다.
  그래서 표 만들기가 「머지 직전」이 아니라 프리뷰를 띄우는 시점에 이미 필요했다
- **프리뷰는 Vercel Authentication 으로 막혀 있다**(모든 경로 302). 휴대폰으로 프리뷰를 열려면
  그 폰에서 Vercel 에 로그인해야 한다 — 실기기 확인은 운영에서 하는 편이 낫다
- **`NEXT_PUBLIC_*` 은 빌드 시점에 번들에 박힌다.** 키를 나중에 넣으면 이미 나간 배포는 모른다
- 운영 DB 가 `main` 보다 앞서 있었다 —
  [`troubleshootings/migration-traps.md`](../troubleshootings/migration-traps.md) 에 항목으로 남겼다

## 남는 한계 (코드로 못 푸는 것)

- iOS 는 홈 화면에 추가하지 않으면 푸시가 오지 않는다. 1인당 한 번의 수동 조작이 필요하고,
  그 조작을 코드로 대신할 방법이 없다 (`beforeinstallprompt` 미지원)
- iOS PWA 구독은 한동안 안 쓰면 만료된다. 만료되면 설정에서 다시 켜야 한다
- 크롬으로 열어 둔 아이폰 사용자는 사파리로 옮겨야 한다 — 카드가 그렇게 말한다
