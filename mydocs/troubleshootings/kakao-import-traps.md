# 카톡 이식 파이프라인에서 실제로 밟은 함정

각 항목은 실제로 틀렸다가 실측으로 잡은 것이다. 추측으로 적은 것은 없다.

## 1. `LIKE '__%'` 는 "밑줄 둘로 시작" 이 아니다

SQL LIKE 에서 `_` 는 아무 글자 한 개다. `content NOT LIKE '__%'` 는 두 글자 이상인 모든 본문을 걸러 버린다.
색인 대상 메시지가 9,136건 중 **0건**으로 나왔다. `NOT LIKE '\_\_%'` (백슬래시 이스케이프)로 고쳤다.
Prisma 태그 템플릿 안에서는 `'\\_\\_%'` 로 쓴다.

## 2. CSV 파서는 처음 이식과 바이트 단위로 같아야 한다

메시지의 멱등성 키가 `sha1(방|시각|작성자|본문)` 이라 본문의 줄바꿈 하나가 달라지면 같은 메시지를 다시 넣는다.
처음 이식은 파이썬 `csv` 모듈(universal newline: `\r\n`·`\r` → `\n`, Date 빈 행은 앞 메시지에 `\n` 으로 이어 붙임)이었다.
새 TS 파서로 옛 CSV 를 다시 읽어 **9,136건 전부·세션 id 615개 전부** 일치를 확인한 뒤에야 썼다.
CSV 에는 `\r` 이 71곳 있었다 — 이걸 접지 않았으면 71건이 중복됐다.

## 3. `UPDATE "Task" SET updatedAt = createdAt WHERE sourceId LIKE 'kakao-task:%'` 는 남의 갱신을 지운다

처음 이식 스크립트의 `updatedAt` 교정은 이식 카드 **전부**를 대상으로 했다. 두 번째 이식부터는 먼저 들어간 카드를
사람이 손본 갱신 시각까지 `createdAt` 으로 되돌린다. 이번 실행에서 만든 카드 id 만 `IN (...)` 으로 좁혔다.
Prisma 태그 템플릿에서 `IN (${ids.join(",")})` 는 문자열 하나로 바인딩된다 — `Prisma.join(ids)` 를 써야 한다.

## 4. Claude Code 안에서 `claude -p` 를 돌리면 중첩 실행이 막힌다

자식 프로세스가 `CLAUDECODE` 환경변수를 물려받는다. `askClaude` 에서 지우고 실행한다.
출력은 `--output-format json` 의 `.result` 를 읽는다. 모델이 코드블록으로 감싸는 일이 있어 `[`…`]` 만 잘라 파싱한다.

## 5. 채팅 청크에 시각이 없으면 작년 "오늘" 이 오늘이 된다

청크가 `"정우창의 메시지" + 본문` 뿐이었다. "오늘 최종 업데이트해서 발행했습니다" (2025-09-10) 를 옴니스 AI 가
"오늘(2026-09-07) 발행" 으로 답했다. `[채팅 2026-08-27 14:27] 이름: 본문` + `관련 업무:` 로 바꿨고,
그 뒤 같은 10문항의 근거 적중이 15/27 → 21/27. 형식이 바뀌면 이식 CLI 의 임베딩 단계가 해시 비교로 전량 다시 싣는다.

## 6. 품질 평가가 평가 대상을 오염시킨다

이식 **전** 기준선을 재면서 `#애드힐 …` 추가지시를 보냈더니 옛 카드("애드힐 영문표기 확정")에 붙어 재구성됐고,
그 재구성 결과가 이식 **후** 답변에 근거로 섞였다. 재구성 시나리오는 마지막에 한 번만, 프로덕션에는 돌리지 않는다.
로컬 스냅샷은 `npm run db:snapshot` 이 지운다.

## 7. psql 에서 `timestamp at time zone 'Asia/Seoul'` 은 KST 로 바꾸는 게 아니다

`timestamp without time zone` 에 `at time zone` 을 붙이면 "그 값이 서울 시각이다" 로 해석해 UTC 로 **바꾼다**.
사진 시각 매칭을 시험하려고 DB 에서 시각을 뽑았다가 9시간 두 번 어긋난 파일명을 만들었고, 코드가 틀린 줄 알았다.
Prisma 는 UTC 로 저장하므로 원본(KST)에서 직접 계산하거나 `at time zone 'UTC' at time zone 'Asia/Seoul'` 로 두 번 건다.

## 8. 저장소가 공개다

품질 시나리오에 실제 거래처·과제 이름이 들어간다. `import-tools/eval-*.json` 을 `.gitignore` 에 넣고
`KAKAO_DATA_DIR/eval/` 에 둔다. 분류 프롬프트의 프로젝트 어휘도 파일에 박지 않고 `final.json` 에서 채운다.
