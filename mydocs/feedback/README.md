# feedback — 사람이 쓰는 곳

여기는 **AI 가 채우지 않는다.** 나머지 `mydocs/` 는 AI 가 쓰고 사람이 검토하지만,
이 폴더만 반대다.

적을 것: 결과물의 어디가 왜 잘못됐는지, 다음에는 어떻게 하길 바라는지.
"이 부분이 틀렸다"보다 **"왜 틀렸는지"** 가 훨씬 쓸모 있다 — 이유가 있어야
같은 판단이 다른 상황에서도 재현된다.

파일명은 `{yyyy-mm-dd}-{주제}.md`.
